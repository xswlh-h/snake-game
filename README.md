# 🐍 贪吃蛇小游戏

一个使用纯 HTML + CSS + JavaScript 编写的经典贪吃蛇游戏，无需任何依赖，打开即玩。

## ✨ 功能特性

- 方向键 / WASD 控制蛇的移动方向
- 空格键暂停 / 继续 / 重新开始
- 实时得分与本地最高分记录（localStorage）
- 吃到食物后蛇身增长，每 50 分自动加速
- 移动端虚拟方向按钮自适应显示
- 渐变蛇身配色 + 脉动食物效果

## 🎮 如何游玩

1. 用浏览器打开 `index.html`
2. 按空格键或点击画布开始游戏
3. 使用方向键（或 WASD）控制方向
4. 吃到红色食物得分，撞墙或撞到自身则游戏结束
